INSTALL
1. Close Microsoft Word.
2. Right-click the downloaded ZIP file > Extract All.
3. Open the extracted folder and double-click  install.cmd
   (If Windows shows "Windows protected your PC", click "More info" > "Run anyway".
    AB Layout is installed only for you; no administrator password is needed.)
4. Open Word. Click the "AB Layout" tab on the ribbon.

REQUIREMENTS
- Windows 10 or 11 with desktop Microsoft Word 2013 or later (2013, 2016, 2019, 2021, 2024 or Microsoft 365).
- .NET Framework 4.8 (already part of Windows 10/11).
- No internet connection needed after installation.

REMOVE
Double-click uninstall.cmd (or run uninstall.ps1 in %LOCALAPPDATA%\Programs\AB Layout).
Your custom profiles in %APPDATA%\AB Layout are kept.

IF THE TAB DOES NOT APPEAR
Word > File > Options > Add-ins > Manage: COM Add-ins > Go > tick "AB Layout".
If it is listed under Disabled Items, enable it there.
