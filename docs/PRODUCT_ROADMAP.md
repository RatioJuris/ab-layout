# Product Roadmap

*Developed by PrajnaBytes International Private Limited and RatioJuris · GPL-3.0-or-later*

## Done in 4.0.0

- Check Document (formatting consistency, numbering, legacy fonts, blanks,
  highlights, colour, comments, tracked changes, paper size, blank lines,
  space indents, manual line breaks) with "Show" navigation.
- Clean Document with 7 profiles, preview, stale-document guard, text
  verification and Restore.
- Custom profiles, local storage, share by copy/paste.
- Kruti Dev ↔ Unicode conversion (selection or whole document).
- Page layouts repaired (A4 Supreme Court preset added with citation).
- New icon, valid manifest, GPL-3.0 with attribution terms, tests.

## Next (highest value first)

1. **Real-Word validation pass** (Windows desktop + Word for the web) using the
   manual checklist; fix any API behaviour differences found. *Single most
   important next step — nothing replaces testing in Word itself.*
2. **Pilot with 5–10 advocates** (district court Hindi belt, High Court
   junior, metro practitioner) to validate the hypotheses in
   PRODUCT_RESEARCH.md §14 — especially the default profile and classification.
3. **Court presets with citations** for High Courts advocates ask for
   (Bombay inner/outer margins need mirror margins; Delhi; Allahabad).
4. **Other legacy fonts**: Chanakya, DevLys, Shree-Lipi; regional scripts.
5. **Safe numbering assistant**: convert typed numbers to Word numbering only
   after showing every "para N" reference found in the text, user confirms.

## Later / investigate

- Print readiness: header/footer page numbers, widow/orphan control, keep
  "VERSUS" with party lines.
- Index / list of dates helpers using tables.
- Heading styles from manual headings (for navigation pane and TOC).
- Optional removal of manual line breaks and double spaces (text change →
  separate, explicit, previewed action like the Hindi converter).
- Localised UI (Hindi first).

## Deliberately not planned

AI drafting/research/summaries, accounts, subscriptions, case management,
billing, cloud storage, e-filing integration, server-side processing.
